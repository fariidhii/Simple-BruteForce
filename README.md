Pada repository ini terdapat sebuah tools brute force simple yang dimana akan memecahkan password dari zip yang tersedia.
dimana terdapat sebuah zip dengan password "admin" serta wordlist yang berisi password random yang akan digunakan pada saat menggunakan tools brute force

cara penggunaan :
bukalah tools tersebut di terminal dengan cara
"python bruteforce_simple.py"
maka tools akan meminta path dari zip nya berada serta akan meminta juga path dari wordlist yang sudah disediakan

setelah itu tools akan mencari password yang benar hingga mengeluarkan output dengan password "admin"
